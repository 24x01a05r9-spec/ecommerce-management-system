# Flask E-Commerce Web Application

## 📌 Project Overview
This project is a Flask-based E-Commerce Web Application developed to provide an online shopping experience with product management and order tracking functionality. The system supports user authentication, shopping cart management, and admin product control.

---

## 🚀 Features

### User Features
- User Registration
- User Login & Logout
- Browse Products
- Add Products to Cart
- View Shopping Cart
- Checkout Functionality

### Admin Features
- Add Products
- Manage Products
- Delete Products
- Role-Based Access Control

---

## 🛠 Technologies Used

- Python
- Flask
- Flask SQLAlchemy
- Flask Login
- SQLite Database
- HTML
- CSS

## ⚙️ Installation Steps

### Step 1: Install Required Packages

```bash
pip install flask flask_sqlalchemy flask_login
```

### Step 2: Run Application

```bash
python app.py
```

### Step 3: Open Browser

```plaintext
http://127.0.0.1:5000
```
